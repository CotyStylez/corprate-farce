# Synergize Your Compliance // Zero-Telemetry Enterprise Farce

A satire enterprise web application built in React and TypeScript. Engineered to convert raw human attention directly into meaningless corporate buzzwords without calling home.

## Features

- **100% Client-Side Architecture**: Zero cookies, zero external telemetry, zero tracking packets transmitted off-device.
- **Particle Dynamics**: Real-time canvas-based particle bursts on interaction.
- **Parody Telemetry Stream**: Live updating corporate jargon synthesizer, telemetry firewall defense simulation, and stubborn middle-management surveillance toggles.
- **Interactive Satire Modules**: Attention Harvester 3000, Thought Predictor AI, Bureaucracy Multiplier, and the Retention Infinite Loop.
- **Extortion Pricing Tiers**: Transparently satirical pricing tiers for the Free Drone, Middle Manager, and Oligarch.
- **Mandatory Legal Illusion Banner**: A self-aware mock cookie banner allowing users to surrender devices or dismiss peacefully.

## Getting Started

```bash
npm install
npm run dev
```

App runs on port 3000 with hot module reloading.

## GitHub Pages Deployment

This project is configured with relative base paths (`base: './'`) in `vite.config.ts` and includes an automated GitHub Actions deployment workflow.

To enable in your GitHub repository:
1. Navigate to **Settings** -> **Pages** in your repository.
2. Under **Build and deployment** > **Source**, choose **GitHub Actions**.
3. Pushing code to `main` will automatically build and publish the site.
